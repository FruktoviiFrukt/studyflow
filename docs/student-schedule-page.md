# Подключение страницы расписания

`/schedule` получает данные через GET /api/schedule. Демо-генератор больше не
используется на этой странице. Форма профиля и импорт PDF этим шагом не добавлены.

## Изменения

- `components/schedule/schedule.tsx`: запрос понедельник–воскресенье при смене
  недели, состояние загрузки, ошибка и повтор запроса. Старые запросы отменяются
  через AbortController и не могут обновить страницу после смены периода.
  Переключение дня внутри загруженной недели не делает новый запрос.
- Показываются группа, подгруппа и учебная чётность из ответа API. При отсутствии
  профиля — инструкция и кнопка повторной проверки; ссылки на несуществующую
  страницу профиля нет. При 401 кнопка повторного входа очищает старую сессию.
- Пустой день, каникулы и отсутствие публикации имеют разные сообщения.
- `components/schedule/week-grid.tsx`: семь пар, включая 18:45–20:15, все семь
  дней недели; дополнительные интервалы API тоже отображаются. Сетка прокручивается
  горизонтально на узких экранах. Состояние каждого дня показано в заголовке.
- `components/schedule/lesson-card.tsx`: предметы и время из API, необязательные
  подробности, скрытие отсутствующей темы. Демоподпись остаётся только у старых
  данных аттестаций.
- `lib/student-schedule-view.ts`: тип ответа, перевод типов занятий и времени
  для интерфейса, безопасная палитра с цветом по умолчанию. Общие компоненты
  продолжают поддерживать старые данные аттестаций.

## Проверки

`npx playwright test --config playwright.schedule.config.ts` запускает отдельный
локальный сервер на 3102 и 3 сценария: данные/карточки/мобильная сетка, состояния
ошибки/профиля/публикации и запоздавший ответ старой недели. Тесты подписывают
сессию тестовым секретом и подставляют HTTP-ответы расписания. Это проверка
контракта интерфейса, не полный сценарий регистрации и чтения настоящей БД.
Из основного Playwright config этот отдельный набор исключён.

Для проверки на реальных данных нужны работающая БД с миграциями, пользователь
с groupId/subgroupId и опубликованное расписание с занятиями для его группы.
Без этого страница показывает соответствующее пустое состояние. Новая миграция
или установка зависимостей не требуется.

Админка, полуавтоматический импорт PDF, сохранение и публикация реализованы.
Актуальный запуск и ограничения описаны в `admin-schedule-import.md`.
Выбор группы/подгруппы в профиле остаётся отдельной задачей.
